# Rejected Olympic Sports 01

Deterministic one-line rejected-sport writer for the make.fun competition
"Rejected Olympic Sports".

`main.ts` holds a hand-written list of original invented Olympic events,
scores each against the judge's brief (funny, plausible enough to sound
like a broadcast, tight, quotable), and writes the winning line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/`).

Run: `node main.ts` (Node 22, zero dependencies).
